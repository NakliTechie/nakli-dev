📖 Books

A browser-native reader for ePub and PDF, built for nakliOS. Drag a book in, read it where you left off, take notes in the margins.

Planned for v1:

  • Library view — covers in a grid, sorted by recently-read
  • ePub + PDF rendering via epub.js / pdf.js
  • Reading position synced across devices via the nakliOS folder
  • Highlights + margin notes, stored alongside each book
  • Reader chrome respects nakliOS theme

Storage: apps/books/library/*.epub and apps/books/notes/<book-id>.json in your connected folder.
