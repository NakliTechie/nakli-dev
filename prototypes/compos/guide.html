Compos in NakliOS

NakliOS carries Compos’s native browser client through a paired loopback relay. It does not mirror editor state or introduce another application protocol.

Before you begin

  • Git, Elixir, and Erlang/OTP are installed.
  • Node.js 20 or newer and mkcert are installed.
  • You can run two terminal sessions.

1 · Install and start Compos

git clone https://github.com/svs/compos
cd compos
mix deps.get
mix run --no-halt

Keep this terminal open. Compos serves its native client on http://127.0.0.1:4004 and stores its state under ~/.compos.

2 · Download and trust the Compos relay

Open another terminal:

curl -fsSLO https://compos-relay.naklios.dev/compos-relay.mjs
curl -fsSLO https://compos-relay.naklios.dev/setup-local-tls.sh
sh setup-local-tls.sh
node compos-relay.mjs

The relay prints nakli-compos-relay listening, a pairing code, and a pair URL. Keep this terminal open too.

setup-local-tls.sh shows the trust-store action, runs mkcert -install, and creates a certificate unique to this machine. The relay download contains no private key.

3 · Pair

  1. Open the Compos prototype.
  2. Paste the terminal’s pairing code.
  3. Select Connect.
  4. If Chrome asks for local-network access, allow it for naklios.dev.

The pairing code is consumed after the first accepted request. The relay replaces it with an HttpOnly session cookie and removes it from the URL.

Security boundary

Compos’s JSON-RPC socket exposes eval without authentication. The prototype never forwards that socket. The relay proxies Compos’s HTTP and WebSocket client behind one in-memory session and an Origin allowlist.

Keep the relay on its default loopback bind address. Do not set BIND_HOST to a public interface.

Troubleshooting

“Compos is unavailable”

Check the first terminal. Open http://127.0.0.1:4004 directly. Restart mix run --no-halt if it does not load.

Pairing code refused

The code has already been consumed or was copied incompletely. Restart node compos-relay.mjs to mint another code.

The frame keeps waiting

Allow Chrome’s local-network prompt. Confirm that the relay reports https://local.naklios.dev:9130. Rerun sh setup-local-tls.sh if the browser does not trust the local certificate.

Repository development

A source checkout can run without TLS beside a local static server:

python3 -m http.server 8000
DISABLE_TLS=1 node prototypes/compos/compos-relay.mjs --port 9130

Open http://localhost:8000/prototypes/compos/ and set the endpoint to http://127.0.0.1:9130.
