setup guide

Your Compos context, inside NakliOS.

This prototype does not reimplement Compos. It carries the native Phoenix LiveView client from your local daemon through a paired loopback bridge. Compos remains the source of truth for buffers, windows, agents, and commands.

1
Start Compos: mix run --no-halt.
2
Download the Compos relay and create its local TLS certificate. The setup guide has the three commands.
3
Paste the pairing code printed by the bridge, then connect.
The pairing code stays in this page long enough to establish one bridge session.
